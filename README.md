# Game Revenue Analysis

This project analyzes game payment behavior and revenue trends using SQL and Tableau.

The analysis focuses on:
- Monthly Recurring Revenue (MRR)
- Churn Rate
- Revenue Churn
- New Paid Users
- Expansion & Contraction Revenue
- Average Revenue Per Paying User (ARPPU)
- Lifetime Value (LTV)

---

## Tools Used

- PostgreSQL
- SQL
- Tableau

---

## SQL Techniques

This project includes:
- CTEs
- Window Functions
- LAG / LEAD
- Aggregations
- Revenue Modeling
- Churn Analysis
- Lifetime Metrics

- How much revenue is lost due to churn?
- How does customer lifetime value differ by segment?
